# Bangla Flashcards

689 illustrated flashcards for learning Bangla: 60 letters and sounds, 248 verbs, 211 nouns, 105 adjectives, 41 postpositions and 24 question words.

Open the site on a phone, tap **Share → Add to Home Screen**, and it works offline from then on. The home screen links to `Bangla-grammar-guide.pdf`, a reference guide to the letters, the grammar and the cards. Study progress is stored only in your own browser on your own device; nothing is sent anywhere.

See `CREDITS.md` for artwork and font licenses.
