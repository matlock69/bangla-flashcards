# Bangla Flashcards

519 illustrated flashcards for learning Bangla: 60 letters and sounds, 248 verbs and 211 nouns.

Open the site on a phone, tap **Share → Add to Home Screen**, and it works offline from then on. Study progress is stored only in your own browser on your own device; nothing is sent anywhere.

See `CREDITS.md` for artwork and font licenses.
